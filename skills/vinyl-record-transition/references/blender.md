# Blender Video Sequencer 适配

当用户没有指定剪辑软件，或允许使用已安装的 Blender 时采用此路径。它在独立后台 Blender 中创建原生视频序列编辑工程，并由 Blender 导出视频。不是将最终 MP4 放进软件后冒称完成分层剪辑。

## 前提与执行

- 可运行 Blender 4.5 或 5.2；脚本运行在 Blender 自带 Python 内，不使用普通 Python 运行 `build_blender.py`。
- 先按技能的素材准备步骤产生项目目录中的 `recipe.json` 和 `assets/`。
- 保留整个项目目录。工程引用素材的相对路径；单独拷贝 `.blend` 会缺素材。把 `.blend` 放在项目根目录最便于打包。
- 使用新的输出文件名。脚本拒绝覆盖现存 `.blend` 和目标 MP4；它不改动用户打开的软件会话或其他工程。

命令参数均为独立参数；路径带空格时按当前 Shell 正确引用。以下为结构示例，替换实际路径：

```text
blender --background --factory-startup --python-exit-code 1 --python /skill/scripts/build_blender.py -- --recipe /project/recipe.json --output /project/editable.blend --render /project/result.mp4
```

只建工程时省略 `--render`。打开 `editable.blend` 后可在视频序列编辑器调整轨道、旋转关键帧和时长。面板、文字和图标是独立透明 PNG 图层；改文字需重新准备对应 PNG，不应称为原生可编辑文字。

## 工程结构

1. 前段全屏背景。
2. 后段同一背景保持原有时间，向右平移；不会重新从源片开头播放。
3. 白色羽化遮罩和灰色横条。
4. 黑胶图片，原生旋转关键帧。
5. 圆形照片，原生旋转关键帧，与黑胶同心。
6. 标题及播放器装饰。
7. 云朵 PNG 动画序列，处于高层。
8. 可选声音轨道。

转场遮挡中点由 `transition.switch` 定位。准备工具必须保证该时刻云朵全屏不透明，遮住背景平移和播放器图层出现；不能仅用不遮满画面的白边隐瞒硬切。圆形照片和黑胶从该时刻开始匀速顺时针转动；每圈时长取 `rotation_seconds`。

API 会探测 `strips` / `sequences` 与新版 Action 分层曲线，不依赖固定 UI 菜单。不同 Blender 版本仍需实际运行并验证，不能把探测代码等同于所有版本已兼容。

## 必须核验的结果

- 命令成功，真实 `.blend` 与要求导出的 MP4 均存在且非空。
- 重新打开 `.blend`，核对分层、素材是否缺失、旋转关键帧、云朵序列和可选音轨。
- 检查输出尺寸、帧率、时长和解码；分别查看转场前、中、后，以及旋转中段，确认照片没有变形、裁切或套在错误位置。
- 若可用，连续播放导出文件进行视觉与听觉检查；无法完成时据实标记待核验。抽帧和波形不能代替全片听看。
- 有声音输入才宣称有音轨；`files.audio=null` 时本路径输出静音视频，不擅自下载音乐或让用户以为有原声。

本适配的测试证据应记录具体 Blender 版本和产物，保存在任务输出目录；跨 Agent 的可移植性不代表每种 Agent 或每款剪辑软件都已实测。

## 工程可迁移性

将整个工程目录（含 assets/）复制到独立位置，用后台进程重新打开。核对每个片段的媒体、黑胶与封面的旋转曲线、云朵帧数和音轨。渲染转场前、中、后各一帧，再用第二组不同素材、相同设置检查背景和圆形封面随输入变化。检查时记录 Blender 版本、所用画幅、时长和输入类型。同一机器上的成功运行只说明该测试组合可用。
