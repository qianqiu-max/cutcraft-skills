# 前景遮挡与输出检查

## 先看实际素材

保护前景不限于脸或身体：按需求包含头发、衣袖、衣摆、手脚，以及伞、帽子等与人物相连的物件。先查看当前素材，再确定轮廓。**任何上一条视频的人物坐标都不能直接复用到另一张素材。**

合成顺序从下到上：原背景 → 流动字与全部光晕 → 原素材中的人物前景。只有人物前景和背景使用完全相同的裁切、缩放与时间位置，文字才会自然穿到人物身后。遮罩完成后不再添加会将光晕扩散回人物身上的全局模糊。

编辑器原生智能抠像或经过检查的分割结果可直接使用。静态图片也可用下面的显式轮廓脚本。脚本只负责忠实绘制已提供的轮廓，不会自动识别人像，更不把一个大矩形当作人物遮挡。

## 静态图片的通用坐标格式

`shapes.json` 示例仅说明格式，坐标是抽象示例，**不是可直接套到素材上的默认人像**：

```json
{
  "coordinate_space": "normalized",
  "shapes": [
    {"type": "polygon", "points": [[0.42, 0.2], [0.56, 0.2], [0.61, 0.9], [0.36, 0.9]]},
    {"type": "line", "points": [[0.6, 0.15], [0.6, 0.5]], "width": 0.004}
  ]
}
```

- `normalized`：点坐标为 0..1，分别乘图像宽、高；线宽为图像短边比例。
- `pixels`：必须另外提供 `source_size: [W, H]`，且与原图完全相同；点与线宽用原图像素。
- 坐标与 `source_size` 一律基于 **按 EXIF 方向转正后的显示图像**，不是 JPEG 文件中尚未转正的存储尺寸。`make_mask.py` 与 `prepare.py` / 渲染器均先执行相同的 EXIF 转正；例如存储尺寸 120×80、orientation=6 的照片，其描边坐标尺寸应为 80×120。
- `polygon` 至少 3 点，`line` 至少 2 点。所有形状取并集为白色前景；其余为黑色背景。
- `--expand` 和 `--feather` 始终以原图像素为单位。先选约 2–3 像素安全余量，再看实际边缘调整；不把固定值泛化为所有分辨率。

```text
python <SKILL>/scripts/make_mask.py --image <IMAGE> --shapes <SHAPES_JSON> --output <PROJECT>/assets/mask.png --review <PROJECT>/assets/mask-review.jpg --expand 3 --feather 0.8
```

输出为原图尺寸的灰度 PNG。已描画的主体内部强制保持 255，只在外围安全余量柔化，避免文字从人物内部透出。查看检查图，特别检查指缝、发梢、衣摆、伞杆；复杂透明物件不应靠随意加大膨胀范围解决。

脚本默认拒绝覆盖现有文件，确需替换指定输出时才加 `--overwrite`。始终保留原始素材。

## 动态视频

动态人物需要随时间变化的抠像/跟踪结果。优先使用剪辑软件逐帧分割与跟踪，或输出与原片尺寸、起点、帧率/时间戳相匹配的灰度遮罩视频。主体移动、镜头运动、景别变化时，单帧遮罩不成立；不得因一张抽帧看似合适就把静态遮罩覆盖全片。

在镜头切换、快速运动、手脚离开身体、头发/伞边缘处增加检查。轮廓丢失时修正关键帧并向前后传播，不用一块持续空白区域掩盖跟踪失败。若当前工具无法可靠抠像，应交付待修复工程并明确缺口，不把遮挡保护标为通过。

## 技术检查与透明层检查

```text
python <SKILL>/scripts/inspect_output.py --video <MP4_OR_MOV> --output-dir <PROJECT>/checks --samples 12
```

该工具使用 PATH 中的 FFprobe/FFmpeg，执行全片技术解码、抽取首段至末帧前的合法时间点，输出 `inspection.json`、逐帧 PNG 和联系表。默认拒绝覆盖同名检查结果；复查时使用新目录，或明确指定 `--overwrite`。

透明 MOV 不能只凭 `.mov` 扩展名或 `yuva` 元数据判定成功。工具会把实际解码的 RGBA 帧放在棋盘格上，统计真实 alpha 的最小/最大值与半透明比例。正确的文字层应同时存在可见笔画和透明背景；全透明也是失败输出。若输入是合成 MP4，alpha 全 255 是正常情况。

这些结果只证明技术解码和被抽查的画面/透明通道，不等同于完整动态观看或听审。交付前还应在播放器或编辑器中播放成片：确认从左向右的流速、循环接点、人物边缘、文字密度及音频；未完成的项目如实标为待核验。
