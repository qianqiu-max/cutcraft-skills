# 检查运动、遮挡和导出

1. 在同一字列经过主体前、中、后取帧。记录它的画面横坐标和人物边缘。字列向右移动，近层比远层快。连续播放检查速度跳变、离屏循环和光晕闪烁。
2. 固定输出画幅和时间。在保护区对比合成前后的主体，重点看发梢、衣袖、道具、半透明边缘和镜头切换；透明字层本身应该在主体所在位置仍有文字，遮挡由前景合成完成。
3. 检查 MOV 的编码、像素格式，抽取 alpha 通道确认同时有透明和可见区域，在实际编辑器内叠一层棋盘格复查。输出 MP4 做完整技术解码，并核对音轨和时间范围。
4. 移动工程及媒体到新目录复开。交付时说明字体名称、授权和替换方法，系统字体不会随包分发。检查字体笔画、标点及缺字。
5. 对桌面软件的抠像、关键帧与透明通道导入进行现场核实。动态蒙版需与每一帧同步。逐帧像素检查、连续观看和全片听审分别记录。
