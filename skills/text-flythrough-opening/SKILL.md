# 文字穿越开场

需要一段视频或一张照片。优先使用连续运动、明暗有层次的镜头。用户有片名就照用，未指定时按素材取一个简短标题。短片名配较粗的字体更容易读清，主画面开场就有运动时，字形内部也要同步显示这段运动。

## 两段动作

1. 从黑场开始，居中的标题由小到大、由暗到清楚。在教程里，「放大」入场持续约两秒。笔画是看见视频的窗口，字洞和字外仍是黑色。
2. 标题可读后，整组字迅速放大并平移，让视线进入其中一条实心笔画。推到这笔的内部覆盖画面四角，随后延续同一镜头。底片从头到尾以相同取景和时间连续播放。字模放大时，字里的景物保持原来的比例。

剪映版本的图层关系、关键帧和时码见[剪映复刻步骤](references/editor-steps.md)。

## 用自己的素材执行

需要 Python 3.10+、Pillow 9.1+、FFmpeg 和 ffprobe。终端应能执行 `ffmpeg -version` 与 `ffprobe -version`。缺少 Pillow 时运行 `python -m pip install "Pillow>=9.1"`。从本技能目录执行下面的命令，将示例文件、片名和工程名换成本次输入，用一个新目录建工程。

```sh
python scripts/render.py init --source "assets/departure.mp4" --title "启程" --project "启程工程" --width 960 --height 540 --fps 30 --duration 6
python "启程工程/render.py" render --project "启程工程"
```

上述命令直接使用随包的[原创海边车站底片](assets/departure.mp4)和「启程」字模，可在没有中文字体的环境中重做展示样片。底图以生成图像制作，沿站台轻推镜头，并配有自行合成的站台环境声。示例字模由 Noto Serif SC 栅格化。

把 `--source` 换成自己的图片或视频即可。带声输入默认保留第一条音轨，静态图可以安静地开场。换片名时可用 `--font "字体文件.ttf"` 指定有权使用、覆盖所用字符的字体。改变画幅时一并设置宽高，例如竖屏使用 `--width 540 --height 960`，并检查居中裁切后是否仍保留主体。

## 改片名、穿入点与节奏

修改工程中的 `recipe.json`，进入工程目录运行 `python render.py render --project .`。未改字时会复用自带的栅格字模。保留默认的自动锚点，换片名后脚本会重新寻找实心笔画并计算最终放大倍率。换字体时在重渲命令里加上 `--font`。

| 想改什么 | 参数与作用 |
| --- | --- |
| 片名和居中位置 | `title.text` 指定单行标题。`title.center` 是相对画面宽、高的坐标，`[0.5, 0.5]` 表示居中。`title.max_width` 和 `title.max_height` 限定清楚可读时的最大尺寸。 |
| 入场与穿越用时 | `motion.entrance_end` 是第一段结束时刻，`motion.fill_time` 是完全穿过的时刻，单位均为从片头算起的秒数。六秒样片可先试 2 秒和 4 秒，其余两秒保留完整景物。 |
| 从哪一笔穿过 | `motion.anchor` 默认 `"auto"`。若要穿进指定部首，可改成字模内归一化坐标 `[x, y]`。先查看工程的 `media/glyph.png`，选择白色笔画内部，避开黑色字洞与抗锯齿边缘。 |
| 镜头感和声音 | `motion.entrance_scale` 是渐显开始时相对片名字号的比例，`motion.zoom_exponent` 调整第二段的加速程度。`audio.preserve` 设为 `false` 可导出静音版。 |

## 交付前核对

- 开头有一段能读清的完整片名。看字形内部的画面是否随原视频播放，字体是否缺字、选景是否太暗。
- 检查穿入点位于实心笔画内。更换成“回”、O 或较细的字时，要重新确认穿入位置和最终倍率。
- 找一处容易辨认的背景细节，例如车站柱子。字形放大时柱子应保持底片中的大小和位置。检查将要满屏的最后几帧，四角应逐步显现。
- 交付 `output.mp4` 和完整脚本工程，保留 `recipe.json`、渲染器、主素材和字模。移动工程后重渲一次。对带声视频核对原声的起点、连续性和结尾，分别记录技术检测、视觉复核和听审。
