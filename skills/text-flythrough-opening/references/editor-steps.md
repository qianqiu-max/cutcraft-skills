# 用剪映制作文字穿越开场

准备一段准备展示的画面，以及一个短片名。先搭出可单独预览的黑底白字动画，再用风景填充字形。这样可以在导入画面前发现笔画空洞或边角露黑的问题。

## 建立四秒的文字动画

1. 在主轨放一段黑色背景，添加居中的白色文字。两到四个字容易快速读清。选择笔画较厚、至少有一处宽实笔的字体，给文字留出四周黑色空间。可先把完整片名放到约四成画宽，再按字数调。
2. 选中文字，进入「动画 → 入场」，选「放大」，把时长调为 **2 秒**。回到时间线从头试看，小而暗的字逐渐变大、变亮，到第 2 秒左右能读全片名。
3. 播放头停在入场动画结束处，给文字打一个位置与缩放关键帧。向后移动 **2 秒**，双指放大文字，同时调整位置，把一块宽实笔对准画面中心，直到预览中从中心到四角都呈白色。目标落在笔画内部；若落在两字间隙或封闭字腔，穿过后会留下黑洞。
4. 回放黑白动画。前两秒供观众认字，后两秒让笔画边缘快速越过屏幕，上下左右的黑边依次退场。出字后保留一小段满画幅画面。

## 用自己的素材填充文字

1. 打开「画中画」，导入要展示的视频或照片，与黑底片头对齐起点，让画面铺满目标画幅。已有原声的视频用这条画中画提供声音。
2. 选中画中画，在「混合模式」中选 **正片叠底**。打开「层级」，把这段画中画移到文字前面，使它处于能与下方黑白文字合成的位置。
3. 在字形的白色区域应当看见素材，在黑色区域仍为黑场。画面自己的镜头运动全程连续，缩放关键帧加在文字上。若仍看到盖在素材上的白字，检查画中画与文字的前后次序。定格在笔画放大的中途，画面里同一个物体应维持底片原有的大小。
4. 到开满的时间点，把前后两帧与底片对应时间对照。看四个角和字腔是否干净，听原声有没有突然跳变。需要接后半段时延续同一素材时间线。

一次复刻先按 2 秒入场加 2 秒穿过制作。字体、标题宽度、放大倍数和瞄准点取决于实际片名及画幅。换成细字、空心字或另一种书法字后，重新寻找实笔，再调终点放大倍数；每个字形需要的数值可能差得很大。
