# 纸飞机拉幕开场

输入一张照片或一段视频，可附想显示的片名。主画面在标题与幕内共用同一条时间线。优先用一至四个字的短标题，并选择开头字形范围内有亮暗或色彩变化的素材。片名、画幅和速度服从本次素材与用户要求。

## 运行

准备 Python 3.10+、Pillow 9.1+，并确认在终端能运行 `ffmpeg -version` 和 `ffprobe -version`。缺少 Pillow 时可运行 `python -m pip install "Pillow>=9.1"`。下面的命令从本技能目录执行。随包提供[《初雪》的六秒风景底片](assets/alpine-dawn.mp4)，可先用它试跑。替换 `--source` 和 `--title` 即可制作自己的版本。目标工程目录用新的名字。

```sh
python scripts/render.py init --source "assets/alpine-dawn.mp4" --project "旅行开场" --title "初雪" --width 960 --height 540 --fps 30 --duration 6
python "旅行开场/render.py" render --project "旅行开场"
```

- `--source` 也可以指向静态图片。视频沿用源画面的运动和原声。静态图或无音轨视频可输出静音片。
- 竖屏示例可将宽高改为 `--width 540 --height 960`。留意居中裁切后的取景，必要时先裁好底图再建工程。
- 可用 `--plane "折纸飞机.png"` 换成自己的透明贴图。机头朝右上，机尾锚点在实际纸尾，将幕尖接在纸面下。
- 初始化时可用 `--font "标题字体.ttf"` 指定覆盖所用字符的字体。使用自己有权用于成片的字体。

公开样片使用本项目生成的虚构雪山木屋画面，叠加轻微推进、飘雪和自行合成的风声、溪流声。配套的「初雪」字模取自 Noto Serif SC。按上面的参数初始化时，脚本会自动使用随包的字模，因而可在未安装中文字体的环境中复用示例。更换标题或画幅后会重新生成字形。

## 调整和交付

工程中的 `recipe.json` 保存画幅、片名、飞机航线、幕布和声音参数。输入媒体、透明飞机和已生成的标题遮罩都保存在工程内。移动整个目录后，可以用其中的 `render.py` 再次渲染。要大幅更换素材或画幅，用新的 `--source` 新建工程更容易保留原版。交付 `output.mp4` 以及整个工程目录，附上改片名与重渲命令。

| 想改什么 | 修改工程里的参数 |
| --- | --- |
| 换片名、字高或位置 | 改 `title.text`、`title.height_ratio` 或 `title.center`。重渲时可传 `--font`。工程缓存已经生成的字形，换字时需要本机有覆盖新字符的字体。 |
| 改飞机路线与联结位置 | `flight.start_tail` 与 `flight.end_tail` 是机尾在画面中的起止坐标。左上为 (0, 0)，右下为 (1, 1)，画外可超出此范围。`flight.anchor` 是在飞机贴图内部的机尾坐标。 |
| 改飞机远近感 | `flight.plane_width` 和 `flight.end_plane_width` 是飞机起点和终点宽度占画宽的比例，样片从 0.18 渐缩到 0.14。 |
| 调起飞、出画和收幕的节奏 | `flight.start`、`flight.end`、`curtain.finish` 都以秒计。保持开始飞行、结束飞行、幕完全打开的先后顺序。改变曲边弯度可调 `curtain.sag`。 |
| 控制声音 | `audio.preserve` 为 `true` 时使用输入视频第一条音轨，改为 `false` 可输出静音。比底片更长的导出会定格最后一帧，并将声音尾部补为静音。 |

手工在剪映中操作时，可对照[图层、关键帧与参考时间码](references/editor-steps.md)。脚本工程用字形遮罩和可调的双弧曲线重建同类运动，保留可编辑的参数。

## 核对画面

1. **开场**　标题的笔画中已经出现底图，字以外是黑场。留意字有没有缺笔、方框或因选景过暗而看不清。
2. **机尾入画至飞行中段**　飞机向右上飞并逐渐缩小。揭幕从左下开始，上方和右方的边缘都向内凹，尖端紧接机尾。飞机白色折面应清楚可辨。
3. **出画**　飞机先离开，右下余幕继续展开。逐帧检查是否脱节、跳到全屏或残留一条黑边。
4. **开满**　四角与底片相同。字融入底图，运动素材连续，未出现两份错位的风景。有原声的成片从头到尾听一遍，再核对工程重新渲染的结果。
