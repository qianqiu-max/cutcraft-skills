# 在剪映里搭建纸飞机拉幕

先找一段风景和一个短片名。下列时间是从参考演示的第一遍动作估测的取样点。它们描述的是横向成片窗口内的运动，竖向录屏包含的工具栏和字幕不计入构图。换素材时按目标画幅重排。

| 录屏时段 | 操作 | 画面检查 |
| --- | --- | --- |
| 约 0–5 秒 | 观看结果。片头先闪过效果标题，随后完整示范一次。 | 黑底中央的字先透出风景，飞机向右上飞，右下角是最后揭开的区域。 |
| 约 6–23 秒 | 新建黑色主轨，添加朝右上的折纸飞机贴纸，时长与主轨对齐。起点放大并移到左下画外。在后一个位置关键帧缩小飞机，移到右上画外。 | 飞机由近向远。视觉上接近匀速，以斜向移动和轻微缩放为主。 |
| 约 24–46 秒 | 飞机刚露出尾部时添加白色画中画。在蒙版中选「内圆四角星」，把最小蒙版对准机尾，打大小和位置关键帧。到飞机出画时放大蒙版，让可见的尖端仍与机尾相接。再往后设一个更大的关键帧，铺满画面。 | 幕的上沿与右沿都是内凹的曲线。飞机出画时右下仍有黑色，之后连续展开，直到四角都看得到风景。 |
| 约 47–52 秒 | 添加想展示的视频，混合模式选「正片叠底」，对齐时间线。 | 黑色区域保持黑，白色幕内显出风景。移动镜头时，字内和幕内显示同一时刻、同一位置的景物。 |
| 约 53–60 秒 | 在片头添加短标题。在「层级」切到「全部轨道」，按教程把文字拖到最下面，结合前面的混合层检查预览。 | 黑场中只透出字形。展开经过文字时，字形融入完整景物。 |
| 约 61–68 秒 | 回放整个开场。 | 核对机尾与幕尖、飞机出画和最后开满的次序。 |

## 运动怎么对照

以横向成片左上为原点，坐标用画幅宽高的比例表示。首遍约 1.0、1.5、2.0、2.5 秒时，白色飞机的可见包围盒中心依次在 (0.20, 0.78)、(0.39, 0.59)、(0.58, 0.40)、(0.77, 0.21) 附近。这一段飞机宽度从画宽约 17% 缩到 15%。飞机约 3.2 秒完全出画，右下角约 5 秒完全打开。这些是从示范画面估读的时间和位置，包围盒中心与幕尖处的机尾锚点属于两个位置。

教程给出了层次、方向、关键帧先后和混合模式。具体贝塞尔曲线、字幕字体、飞机贴纸、最终画幅和音效可以按素材重定。使用独立渲染器时，以同一底图同时填充字形遮罩和拉幕遮罩，能保留正片叠底在黑白底上的显景关系。纸飞机始终处于前景。
