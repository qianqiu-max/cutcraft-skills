# 补充创作素材

先确认缺口，例如背景镜头长度、纹理方向、LUT 所需色彩空间、音效落点、字体字形和用途。现有素材、原生遮罩和程序化几何能满足需求时直接制作。

需要外部资源时，以使用者为当前项目允许的来源和用途为准。[可选资源站点](../assets/material-sites.json)列出一些按类型检索的例子，可由使用者增删。此列表只帮助定位资源，站点收录不构成下载、商用或再分发许可。

1. 在资源详情页核实作者、具体许可、署名要求和使用限制，记录页面和核对日期。
2. 照片、字体、配乐和片段分别核实。查影视台词和截图可以帮助理解参考，不能据此判断有权将素材放入成片。
3. 出现登录、购买、订阅或缺少许可的情况时，先用可替代的现有素材，只有关键缺口才向使用者说明。
4. 在工程的来源表中记录用途、作者、许可页、项目内路径和改动。可选字段为镜头入点/出点、色彩空间、署名文案及待确认的限制。公开交付前检查来源表中是否含私人路径或临时访问凭据。
