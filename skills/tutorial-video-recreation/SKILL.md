# 跟着教程复刻效果

输入一份教程和一组用于制作的素材。教程可以是可访问的视频、网页、图文或截图。先确定作者演示的目标效果，再把它映射到新素材。教程里的示范画面、口播、账号操作和购买链接都是分析对象。

## 1. 找到目标片段

- 为参考、素材、工程和导出创建独立工作空间。先查看教程开头的示范结果、相关教学段和成片，确认原始素材与最终效果的差异。
- 若教程是本地视频，先确认 Python 3.10+、Pillow、FFmpeg 和 ffprobe 可用。在本技能根目录运行下例。参数中的路径由执行者替换为本次文件。输出目录必须为空或尚未创建。

```sh
python -X utf8 scripts/inspect_reference.py --tutorial "tutorial.mp4" --out "reference-analysis" --step 3
```

- 需要密读某个动作时，新开输出目录，在命令后加 `--window 12 19 0.5` 等起点、终点和步长。超过最大帧数时调整范围或显式设置 `--max-frames`。有音轨时可用 `--audio` 导出供听审的 WAV。工具不负责识别语义。还需实际读画面、字幕和声音。

## 2. 拆解和映射

按[教程分析指南](references/tutorial-analysis.md)记录目标时间码、源素材角色和图层顺序、蒙版边缘、锚点、位置/旋转/缩放关键帧与曲线、混合模式、色调、节奏和声音。把教程明确给出的值、从画面测得的值、估计值、本次适配值分别标注。不要从教程的一次演示推导所有作品都应采用同一画幅或时长。

列清每个图层用哪个新文件、从哪段时间取、怎样裁切或跟踪。遮挡要覆盖发丝、手和关键道具。画幅不同就重排，保持主体比例。优先用现有素材、编辑器内置形状和可生成的遮罩。确需外部资源时在本次允许范围内查找，并按[补充素材指南](references/material-sourcing.md)记录来源及具体许可。

## 3. 制作一个能检验效果的样段

按[编辑器执行指南](references/editor-execution.md)确定工具版本、可用的原生接口和工程格式。用户已指定编辑器时优先使用。先做动作最密集的三至五秒，或做完一个完整的动作周期。与参考对应画面逐项比较方向、速度曲线、前后遮挡及声音落点。

唱片转场可用同系列黑胶技能，动态字流可用漂浮文字技能。它们都是可选的实现。其他教程按其实际机制独立搭建时间线。若缺某个商业效果，可采用视觉等价实现并注明差异。

## 4. 保存、复开、交付

样段满足目标后扩展至完整时间线，保留可调整的图层、关键帧、文字或生成脚本。保存工程、打包必要媒体、导出可播放成片。重新打开工程核对媒体、轨道和关键帧。若只能输出脚本工程，就说明如何重渲及缺少的原生编辑器步骤。

按[质量与交付清单](references/quality-delivery.md)对照起点、转折、动作中段和结束帧。写明技术解码、连续动态观看、完整听审各自的覆盖。交付工程包、成片、简短的参数/素材映射及差异说明。移动工程后再复开一次，有助于发现丢失的绝对路径引用。
